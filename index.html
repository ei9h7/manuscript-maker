Manuscript

Use a fine-grained token limited to your writing repo with read-only Contents permission. A path can be a folder: its .md files are joined in name order. A book.json next to the manuscript sets the layout and front matter.

Word and EPUB files are converted to the manuscript format. EPUB import removes the table of contents, navigation, cover, title and copyright pages, which gives you a clean transcript for print.

A short three-chapter sample with front matter and callouts: sample/manuscript.md and sample/frontmatter.md.

    Front matter

    The pages before chapter 1, in order. This is the same text as frontmatter.md in your writing repo (loaded automatically when present). You can also upload a front-matter file here.

    Format
    • [title] starts a page. Types: title, halftitle, praise, copyright, dedication, epigraph, page, blank, toc.
    • key: value lines right after it set fields: title, subtitle, author, publisher, heading, align: center.
    • Every other line is a paragraph. On praise and epigraph pages, put the source after a spaced dash: Quote. — The Sample Review.
    • Lines before the first page set book-wide values, like year: 2026, isbn: … or cover: cover.jpg (the EPUB cover).
    • Add .print or .epub to a key for a version used in one output only, e.g. subtitle.epub: ….
    • {title}, {author} and {year} are filled in anywhere.
    • // starts a comment line.

    No cover image. Set cover: cover.jpg in the front matter, or choose a file.
